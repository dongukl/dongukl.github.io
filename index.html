// about

새로운 것에 두려움 없이 도전하고, 이해될 때까지 파고드는 방식으로 학습해왔습니다. 막히는 순간마다 원인을 찾아 해결하는 과정을 반복하며 성장하는 것을 중요하게 생각합니다. ROS2를 중심으로 자율 주행 로봇, 매니퓰레이터, 시뮬레이션까지 로봇 개발의 전 영역을 다루고 공부하고 있습니다.

AI Vision을 활용한 TurtleBot4 멀티로봇

유해동물 퇴치 시스템

TurtleBot4 두 대가 웹캠으로 침입 동물을 탐지해 호(Arc) 플랭킹으로 게이트까지 몰아내는 유해동물 퇴치 시스템입니다.

디지털 트윈 기반 Issac sim 시뮬레이션

자동 주유 시스템

Isaac Sim 기반 Doosan M0609 로봇팔 2대가 협업하여 차량 주유구 인식부터 노즐 삽입까지 자동 수행하는 주유 시뮬레이션 시스템입니다.

AI Vision을 활용한 LLM 기반 단일 시연 모방 로봇

협동로봇 스킬 학습

사람이 도구를 한 번 시연하면 그 궤적을 로봇이 재현 가능한 스킬로 변환하고, 이후에는 음성 명령("망치질 해줘")만으로 그 스킬을 불러 실행하는 Doosan M0609 협동로봇 시스템입니다.

  • 비전 파이프라인 전담: MediaPipe Hands로 파지 판정 → GroundingDINO+MobileSAM으로 도구 1회 검출 → CoTracker3 online으로 연속 keypoint 추적 → RealSense depth + RANSAC/Kabsch로 도구 6DoF pose 추정
  • CoTracker online API의 프레임 손실 문제를 직접 발견해 유효 pose FPS를 카메라 FPS 수준까지 개선, SAM 마스크 두께 비대칭으로 도구 머리 방향(앞/뒤)까지 판정
  • GPT(gpt-4o)로 세그먼트별 move_type·속도·blend를 결정하는 스킬 코드 생성 단계 설계 — 좌표는 실측값만 사용해 LLM이 좌표를 지어낼 여지를 구조적으로 차단

AI Vision을 활용한 VLM 기반 로봇 제어

단일 시연 모방 로봇 · Dittobot

사람이 도구를 쥐고 움직이는 단일 시연을 카메라로 관찰해, Doosan M0609가 동일한 궤적과 자세로 그대로 재현하는 시스템입니다. 한 번 녹화된 시연은 스킬로 저장되어, 이후에는 음성 명령만으로 반복 실행됩니다.

Why — 이 문제를 고른 이유

  • 기존 로봇 티칭의 진입장벽 — 산업용 로봇은 전문 엔지니어가 코드 기반으로 직접 티칭해야 동작을 만들 수 있어, 공정이 바뀔 때마다 재프로그래밍에 시간과 전문 인력이 필요합니다.
  • 숙련 인력 확보의 어려움 — 제조업 인력난이 심화되며, 로봇 티칭·재프로그래밍을 담당할 숙련 인력을 상시 확보하기가 점점 어려워지고 있습니다.
  • 목표 — 복잡한 코드 대신 행동 모방과 음성 명령으로 로봇을 가르쳐, 비전문가도 현장에서 바로 쓸 수 있는 티칭 방식을 만드는 것.

My Role

  • 비전 인식 파이프라인 통합 GroundingDINO + MobileSAM으로 도구를 탐지·분할하고, MediaPipe의 파지·포인팅 인식을 결합해 “무엇을 잡았는지”와 “어디를 가리키는지”를 하나의 인식 흐름으로 통합했습니다.
  • LLM 기반 스킬 코드 생성 시연 궤적을 세그먼트로 분류한 뒤, GPT-4o가 각 구간의 movel/movec 선택과 속도·가감속·블렌딩을 판단해 실행 가능한 로봇 코드를 자동 생성하도록 설계했습니다.

What — 시스템 구성

하드웨어

Doosan M0609 협동로봇 + OnRobot RG2 그리퍼 + RealSense D435i RGB-D 카메라

음성 · 인식

웨이크워드 + STT로 명령을 인식하고, GroundingDINO + SAM + MediaPipe로 도구와 손을 함께 인식합니다.

스킬 생성

CoTracker로 추출한 시연 궤적을 세그먼트로 분류하고, GPT-4o가 movel/movec · 속도 · 블렌딩을 결정합니다.

실행 · 관제

검지 포인팅으로 목표 위치를 지정한 뒤 궤적을 재현하고, FastAPI 웹 UI에서 실시간으로 관제합니다.

How — 구현 방식

01궤적 생성 및 스킬화

  • MediaPipe로 손을 인식하고, 파지 시점부터 CoTracker3로 도구 keypoint를 연속 추적
  • Depth deprojection으로 3D 좌표를 복원하고, Kabsch/SVD 정합 + RANSAC 이상치 제거로 도구 자세를 안정화
  • Quaternion 부호 보정과 sliding window 평균으로 회전 불연속·자세 노이즈 제거
  • 스무딩·검증을 거친 궤적을 GPT-4o가 movel/movec·속도·블렌딩으로 판단해 스킬로 변환

025단계 검증 파이프라인

  • record — 도구를 잡으면 녹화 시작, 손을 펴면 종료
  • smooth — 손떨림·추적 노이즈 제거, 꺾이는 지점은 보존
  • verify — 로봇 작업 반경 이탈·급격한 튐 구간 사전 검사
  • replay (dry-run) — 로봇을 움직이지 않고 먼저 시험, 통과해야 실행 버튼이 열림
  • skill — 동작 단위로 변환 후 정확도 점수를 매겨 기준 미달이면 저장 차단

03음성 명령 분류

규칙 기반으로 우선 처리하고, 애매한 발화만 GPT-4o가 판단하도록 분기해 응답 지연과 오판을 함께 줄였습니다.

04안전 작업영역 검사

실행 전 모든 궤적점이 workspace 내부인지, Z축 안전 높이와 waypoint 간 속도 제한을 넘지 않는지 검사하고, 벗어나면 실행을 차단합니다.

Trouble Shooting

미학습 도구를 인식하지 못하는 문제
Problem
기존 YOLO World로는 학습되지 않은 도구를 인식하지 못해, 새로운 도구가 들어올 때마다 파이프라인이 멈췄습니다.
Cause
YOLO World는 open-vocabulary를 표방하지만 실질적으로는 학습된 프롬프트 범위 안에서만 안정적으로 동작했습니다.
Solution
GroundingDINO + MobileSAM 조합으로 전환해, 재학습 없이 임의의 도구를 open-vocabulary로 탐지·분할하도록 개선했습니다. SAM 마스크를 함께 사용해 도구 영역을 정확히 잘라내고, 그 영역에서 CoTracker keypoint를 초기화하도록 연결했습니다.
보정 없는 궤적의 떨림과 오동작
Problem
후처리 없이 시연 궤적을 그대로 재현하면 손떨림이 그대로 반영되어 모션이 버벅이고 오동작이 발생했습니다.
Solution
  • Douglas–Peucker 기반 경로 단순화로 미세 노이즈를 줄이면서 전체 궤적 형상은 유지
  • Prominence 기반 반전점 검출로 망치질 같은 왕복 운동의 타격·방향전환 지점은 보존

Result

1회 시연 → 무한 재실행

한 번 녹화된 시연이 Skill Registry에 등록되면, 이후에는 재시연·재프로그래밍 없이 음성 명령만으로 동일 task를 다른 목표 위치에서도 반복 실행할 수 있습니다.

비전 개선

GroundingDINO+SAM 전환 후 미학습 도구에서도 재학습 없이 탐지에 성공해, 기존 YOLO World 대비 인식 가능한 도구 범위를 넓혔습니다.

LLM 안전성

GPT-4o 출력에 스키마 검증과 기본값 폴백을 적용해, 모든 세그먼트가 실행 가능한 movel/movec 코드로 100% 변환되도록 만들었습니다.

궤적 재현 정확도

망치질 스킬 기준 fidelity RMSE 3.07mm / max 7.73mm, 반전점 5→5 일치로 검증을 통과했습니다.

Learnings

파이프라인 통합 능력

음성·비전·LLM처럼 성격이 다른 모듈을 각각 독립적으로 검증한 뒤 하나의 흐름으로 통합하는 방식을 익혔습니다.

검증 가능한 구조의 중요성

실시간 추종보다 record → smooth → verify → replay처럼 단계를 끊어야 문제 지점을 좁히고 안정성을 확보할 수 있다는 것을 알게 되었습니다.

ROS2 기반 Doosan M0609 로봇팔

자동 조리 시스템 · Wokking Robot

두산 M0609 협동로봇이 QR 주문을 받아 부침개·볶음밥을 직접 조리하는 테이블 오더 시스템입니다. 재료 투입부터 웍 파지, 웍질과 뒤집기, 플레이팅까지 전 과정을 자동화했습니다.

Why — 이 문제를 고른 이유

  • 안전 · 피로 — 고온 화구 앞에서의 반복 작업은 작업자에게 큰 부담이며, 화상은 주방 종사자가 가장 높게 인식하는 잠재 위험 요인입니다.
  • 인력 부족 — 음식점의 인력 부족이 점점 심해지고 있습니다.
  • 품질 편차 — 조리자마다 맛과 공정이 달라져 균일한 품질을 보장하기 어렵습니다.

My Role

  • 로봇 티칭 DART Studio 티칭펜던트로 웍질·부침개 뒤집기 동작의 관절 좌표를 정밀 맵핑했습니다. 단순히 자세를 저장하는 것을 넘어, 화구 간섭을 피하면서 재료가 떠오를 수 있는 관절 조합을 찾는 과정이었습니다.
  • 프론트엔드 개발 손님용 QR 주문 페이지와 관리자 대시보드(실시간 조리 상태 모니터링)를 구현하고, 로봇이 발행하는 조리 단계를 화면에서 바로 확인할 수 있도록 연동했습니다.

What — 시스템 구성

하드웨어

M0609 + RG2 그리퍼. 프라이팬을 안정적으로 잡기 위한 그리퍼 홀더를 3D 프린팅으로 직접 제작해, 그립 경사 홈으로 최대 5mm 오차에도 파지되도록 개선했습니다.

조리 공정

재료 투입 → 웍 파지 → 웍질 및 뒤집기 → 배식까지 전 과정 자동화. 화구 밸브 조작과 불 끄기까지 로봇이 수행합니다.

주문 · 모니터링 UI

QR 주문 → 관리자 조리 시작 → 웹에서 실시간 진행 상태 확인. 관리자 화면에서 긴급정지와 작업 재개가 가능합니다.

예외 처리

사람과 부딪히면 안전 정지 후 재개 가능한 시점에 복귀하고, 그립 실패 시 최대 3회 재시도 후 E-STOP으로 전환합니다.

How — 구현 방식

01웍질 속도 · 블렌딩 제어

  • J2·J5를 역방향으로 동시 회전시켜 각속도를 분산
  • radius blending으로 세트 내 감속을 제거하고 마지막 1회만 정지 → 화구 간섭 방지
  • 복귀 구간의 속도·가속을 더 크게 주어 재료가 관성으로 떠오르도록 유도

02모션 최적화 (강화학습)

  • MuJoCo 상에서 SAC로 웍질 정책을 학습 (총 750 에피소드)
  • 재료량 60/90/120g 조건에서도 궤적 형태가 거의 변하지 않음을 확인
  • 하강각 45°·팬 tilt각 25°로 통일하고, 리사주 궤적으로 팬 전면 균일 교반

03관절 속도 한계 극복

J5 단독 회전으로는 관절 최대속도에 걸려 뒤집기가 불가능했습니다. 프라이팬에서 가장 먼 J2까지 함께 돌려 J2·J3·J5로 회전을 분산해 TCP 속도를 확보했습니다.

04힘 제어 기반 교반

팬 바닥 높이 편차와 재료 두께 변화로 위치 제어에 한계가 있어, 목표 접촉력 Fz −10N을 유지하고 조건을 통과한 뒤에만 교반을 시작하도록 해 헛젓기를 방지했습니다.

Trouble Shooting

웍질 중 모션이 끊기고 재료가 섞이지 않는 문제
Problem
속도가 낮으면 재료가 섞이지 않고, 높이면 안전 모드에 걸려 모션이 끊겼습니다. 종료 후 블렌딩 영향으로 복귀 경로에서 위치 오차와 화구 간섭도 발생했습니다.
Cause
단일 관절 회전만으로는 화구를 회피하면서 충분히 빠른 매끄러운 궤적을 만들 수 없었습니다.
Solution
  • radius blending 적용으로 간섭 제거, 웍질 속도 1.0배 → 1.25배로 상향
  • 복귀 구간의 속도·가속을 더 크게 주어 재료가 관성으로 떠오르도록 조정
  • 마지막 웍질만 blending radius를 0으로 두어 정확한 정지 위치 확보
  • 복귀 시 Via Point(Z=286mm) 추가로 화구와의 충돌 방지
웍 손잡이를 헛잡는 문제
Problem
웍 손잡이 파지 시 그리퍼가 미끄러지거나 회전하면서 웍을 놓치는 현상이 반복됐습니다.
Cause
RG2 그리퍼와 손잡이의 접촉 면적이 좁고 파지 방향이 일정하지 않아, 위치 오차가 생기면 회전 모멘트가 커졌습니다.
Solution
3D 프린팅 보조 지그를 제작하고, Modbus TCP로 그리퍼 폭을 실시간으로 읽어 56±2mm 기준으로 파지 성공을 검증했습니다. 범위를 벗어나면 최대 3회 자동 재파지, 초과 시 E-STOP으로 작업자 확인을 요구합니다.

Result

자동 동작 검증

UI 주문 → 관리자 모드 시작 → 웍질/뒤집기 → 플레이팅까지 한 흐름으로 완주했습니다.

웍질과 뒤집기

  • 웍질 속도를 1.25배로 늘려 재료 섞기 성공
  • 로봇 조인트를 여러 개로 분산해 안전정지 없이 빠른 속도와 힘을 확보
  • → 뒤집기 성공률 95% 확보

기대 효과

  • 조리 시간 단축과 품질 표준화로 운영 효율 향상
  • 위험 작업 대체로 안전한 주방 환경 조성
  • 인력 부족을 로봇으로 대체 가능

Learnings

분산 제어 사고

하나의 관절에 의존하지 않고 여러 관절로 부담을 나누는 유연한 접근으로 물리적 한계를 극복할 수 있다는 것을 배웠습니다.

자연스러운 움직임 설계

궤적만 따라 해서는 사람 동작처럼 나오지 않았습니다. 속도·힘을 강하게 주는 구간을 찾아야 원하는 모션이 나온다는 걸 알게 됐습니다.
